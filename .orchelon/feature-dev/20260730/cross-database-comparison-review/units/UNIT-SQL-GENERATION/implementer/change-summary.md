# UNIT-SQL-GENERATION 修改摘要

- 轮次：round-3
- 已实现目标：round-3 repair-request 四项全部完成。
- 主要修改文件：
  - `consilens-connector/.../oracle/OracleSqlQueryGenerator.java`：
    - checksum 聚合 `COALESCE(RTRIM(EXTRACT(XMLAGG(XMLELEMENT(E, row_checksum || '|') ORDER BY pk_key), '//text()').GETCLOBVAL(), '|'), '')`，去除尾部 `|`、空表对齐 MySQL `''`；
    - 重写 `buildDiffColumnsExpression`（前导分隔符 + `LTRIM` 方案），部分列差异时 diff_columns 非 NULL 且与 MySQL `CONCAT_WS` 输出一致；
    - `stringJoin` 注释说明 Oracle `||` NULL 语义（无其他调用方，保留原实现）；
    - javadoc 补充 `GRANT EXECUTE ON sys.dbms_crypto TO <user>;`。
  - `consilens-connector/.../doris/DorisDataTypeHandler.java`：`normalizeDecimal` 去掉 `CAST(... AS DOUBLE)`（含 precision=0 分支），直接对 DECIMAL 列 ROUND/TRUNCATE 后定标 `DECIMAL(38, min(p,30))`。
- 辅助修改文件：
  - `OracleSqlQueryGeneratorTest`：断言更新为含 `COALESCE(RTRIM(...), '')` 无尾 `|`；新增 `testGetJoinDiffDetailSQLKeepsChangedColumnsWhenOnlySomeDiffer`。

  - `OceanBaseSameDbComparisonTest`：陈旧注释 orders_target → orders_backup（仅注释）。
